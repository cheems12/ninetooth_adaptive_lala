## 第三方依赖

依赖比赛环境提供的海光 DCU、DTK/HIP、Python 3.11 和 PyTorch 2.9.0（HIP 6.3.26093）。源码包含 InfiniCore、InfiniLM 0.1.0、NineToothed 0.26.0、ntops 0.1.0 及各自包含的第三方组件，构建使用 xmake。其他依赖包括 Triton 3.5.1 海光版本、diffusers、transformers 5.14.1、safetensors 0.8.0、tokenizers 0.22.2、huggingface_hub 1.28.0、NumPy、SymPy、Pillow、PyAV、scikit-image 和 FFmpeg；列出的 Python 包版本来自环境离线包，实际导入版本需要按环境核验。不得用普通 PyPI wheel 覆盖平台的海光 PyTorch。模型权重和测试图片不包含在仓库中。

## 完成情况和待改进项

使用统一权重、8 张海光 DCU、首帧 `Golde33443.jpg`、提示词 `A dog falls asleep`、seed 42、50 步、124 帧生成 FL2VA 视频。同步 PyTorch 输入生产与 InfiniCore 读取，缓解多卡位置索引错误造成的生成异常；实验加载了九齿注意力组件。一次完整运行的端到端时间为 1281.610 秒。没有同条件的有效性能基线，因此不声称加速比。

2026-11-08 的复测中，首次启动在加载模型时发生段错误；重试完成去噪并保存了可解码视频，进程随后以段错误退出（退出码 139）。这是已知稳定性问题，后续需定位初始化和退出时的资源生命周期。使用该视频进行独立文件比较时，尺寸和帧数匹配，平均 SSIM 为 96.367%。比较脚本在平台上曾因缺少 `scikit-image` 失败，记录中的相似度是在本机使用同一版本比较脚本和已下载视频得出。

本次成功运行使用预构建的诊断版 `_infinilm.so` 和九齿注意力共享库。干净环境从源码重建、直接加载并完成完整生成尚未验证；九齿重建曾遇到缓存跨文件系统、编译模板读取权限以及链接错误。提交版本、模板文件、离线依赖和许可边界仍需复核。用户提供的图片是否属于官方指定样例及正式相似度阈值未核实。

## FL2VA 比较结果

比较 `InfiniLM/examples/minimax_h3_compare.py` 的 FL2VA 入口，使用同样的图片、提示词与参数生成的已有参考视频和输出视频：

```text
[result] MiniMax-H3 video comparison

  FL2VA
    Size:         PASS (PyTorch 768x928, InfiniLM 768x928)
    Length:       PASS (PyTorch 124 frames, InfiniLM 124 frames)
    Average SSIM: 96.774%
```

第二次复测保存的视频采用同样方法得到 96.367%，但生成进程保存后异常退出；上述两次比较都没有在比较步骤重新生成视频。视频为 24 fps、H.264，音频为 AAC。
