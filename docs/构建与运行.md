## 统一运行入口（实验版）

仓库根目录的 `run_fl2va.sh` 使用仓库提供的预构建海光运行库与部分离线 Python 包。它在临时目录准备组件，不替换平台 PyTorch；首次只检查环境和入口，不生成视频：

```bash
cd /path/to/ninetooth_adaptive_lala
export FL2VA_ENV="$IFAB_AFS_HOME/h3-diagnosis-nov7/restore_env.sh"
bash run_fl2va.sh --check
```

`FL2VA_ENV` 是已有平台环境的可选恢复脚本；脚本会执行该文件，只可指定可信的文件。干净环境中必须自行提供兼容的海光 DTK/HIP、Python 3.11、平台 PyTorch 和缺失的 Python/设备依赖；可用 `FL2VA_EXTRA_PYTHONPATH` 指定额外离线依赖目录。仓库附带部分 wheel 与 diffusers 源码，但不包含完整海光 Triton/FlashAttention 软件包、模型权重或输入图片，不能保证离线依赖完整。检查失败时应按提示补齐匹配版本，**不要用公共 PyPI 的 PyTorch 覆盖平台版本**。

环境检查通过后，使用指定首帧、提示词和新的输出路径：

```bash
export FIRST_FRAME="$IFAB_AFS_HOME/Golde33443.jpg"
export PROMPT='A dog falls asleep'
export OUTPUT="$IFAB_AFS_HOME/outputs/new-run/infinilm_fl2va.mp4"
bash run_fl2va.sh --run
```

默认共享模型路径为 `/public/home/aclsylqidf/shared/MiniMax-H3/diffusers`，可用 `MODEL_PATH` 覆盖；默认 8 卡、50 步、124 帧、seed 42。日志写到 `OUTPUT` 同名加 `.log`。正式评测应按官方指定值设置，不能降低生成工作量。脚本会保留推理进程非零退出码；此前出现过保存视频后段错误，尚未修复。此脚本及所附运行库在干净环境的完整生成尚未验证。

## 主程序构建尝试

以下配置用于独立目录的构建尝试，需在仓库根目录执行。它依赖已安装且匹配的头文件、运行库及相关 Python 包，尚未验证完整执行成功：

```bash
export HYGON_ARCH=gfx936
export HYGON_CUDA_HOME=/opt/dtk/cuda/cuda
export CUDA_PATH=/opt/dtk/cuda/cuda
export DTK_ROOT=/opt/dtk
export INFINI_ROOT="$PWD/install"
export INFINICORE_PYBIND11_INCLUDE=/usr/local/lib/python3.11/site-packages/torch/include
export INFINICORE_PYTHON_INCLUDE=/usr/local/include/python3.11
export INFINILM_PYBIND11_INCLUDE="$INFINICORE_PYBIND11_INCLUDE"
export INFINILM_PYTHON_INCLUDE="$INFINICORE_PYTHON_INCLUDE"
source /opt/dtk/env.sh

cd InfiniCore
xmake f -y -cv -m release --hygon-dcu=y --hygon-arch=gfx936 \
  --cuda=/opt/dtk/cuda/cuda --ccl=y --aten=y --omp=n --cudnn=n
xmake build -y -j 4
xmake install
xmake build -y -j 4 _infinicore
xmake install _infinicore
cd ../InfiniLM
xmake f -y -cv -m release --cxx11-abi=0
xmake build -y -j 4 _infinilm
xmake install _infinilm
```

九齿算子的实验构建和适配脚本位于 `support/h3-build-support/`。实验使用的诊断扩展、插件以及 `mha_full.so` 和 `mha72.so` 已保存于 `artifacts/hygon-gfx936/`，其依赖和限制见该目录说明；从九齿源码生成、适配和链接它们的过程仍需在干净环境验证。`support/restore_env.sh` 与 `support/reproduce_producer_sync.sh` 展示实验使用的既有个人环境和二进制布局，并不具备在全新环境独立运行的能力。
