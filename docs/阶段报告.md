## 完成情况

在 InfiniFabric 8 卡环境中使用 MiniMax-H3 Base FL2VA 权重完成一次 50 步、124 帧的图生视频生成。输入图片为 `Golde33443.jpg`，提示词为 `A dog falls asleep`，随机种子为 42。模型输入由 PyTorch 产生，交给 InfiniCore 读取前加入设备同步，修复了多卡输入位置索引间歇性异常造成的视频噪点。实验运行使用九齿注意力组件及诊断版 InfiniLM 本地库。

继续改进：整理可在干净环境中从源码构建的依赖与脚本，复核九齿组件的编译和加载链路，并重复完整测试。一次运行的端到端耗时为 1281.610 秒；尚无同条件性能基线，因此不报告加速比。

## 复现指令

统一输入图片：`Golde33443.jpg`（与以下两段视频使用同一图片）；统一 FL2VA Prompt：`A dog falls asleep`。

在已准备好的 InfiniFabric 8 卡个人 AFS 环境中，现有实验复现脚本为：

```bash
bash "$IFAB_AFS_HOME/h3-diagnosis-nov7/reproduce_producer_sync.sh"
```

该脚本使用个人 AFS 中已构建的诊断版本地库、环境恢复脚本和共享模型；它还不是干净环境从零编译的完整步骤。仓库、构建脚本和依赖核对完成后需替换为完整指令。

在个人 AFS 中已有两段输出时，单独运行比较脚本：

```bash
cd "$IFAB_AFS_HOME/h3-work/InfiniLM"
source "$IFAB_AFS_HOME/h3-diagnosis-nov7/restore_env.sh"
python examples/minimax_h3_compare.py \
  --model-path=/public/home/aclsylqidf/shared/MiniMax-H3/diffusers \
  --tasks=fl2va \
  --reference-fl2va-video="$IFAB_AFS_HOME/outputs/official-compare-nov5-retry3/reference_fl2va.mp4" \
  --infinilm-fl2va-video="$IFAB_AFS_HOME/outputs/producer-sync-nov7/infinilm_fl2va.mp4" \
  --output-dir="$IFAB_AFS_HOME/outputs/compare-producer-sync"
```

这条平台命令基于已核对的脚本参数编写，尚未在平台端重新运行；已保存的比较输出是在本机调用同一脚本、对下载的两段视频进行比较得到的。
